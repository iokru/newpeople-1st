간단하게 모아두세요

ID와 비밀번호는 홀수 번째 자리의 문자만 입력해 주세요.
짝수 번째 자리는 자동으로 마스킹되어 입력할 수 없으며, 실제 문자 대신 "*"로 LocalStorage에 저장됩니다. (사이트명은 항상 그대로 저장)

사용 방법

한 글자씩 칸에 입력하세요. 짝수 번째 칸(2, 4, 6...)은 자동으로 마스킹되어 입력할 수 없습니다. 칸이 더 필요하면 + 칸 추가를 누르세요.

중요: 이 방식은 암호화가 아니라, 짝수 번째 칸은 아예 입력하지 못하게 막아 "*"로만 저장하는 MVP 방식입니다. 홀수 번째 칸에 입력한 글자는 원본 그대로 LocalStorage에 저장되니, 실제 중요한 계정의 보안 저장소로 사용하면 안 됩니다.
홀수 번째 칸에 입력한 글자만 그대로 LocalStorage에 저장됩니다. 짝수 번째 칸은 항상 "*"로 저장됩니다.
